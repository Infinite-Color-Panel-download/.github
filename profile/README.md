## 🧠 Overview

Infinite Color Panel is a Photoshop panel for colour grading and colour harmony: it exposes curated colour combinations, tonal adjustments and blend modes as buttons, aimed at photographers who grade without leaving the host.

On a Windows machine it runs as a plug-in suite that loads inside Adobe Photoshop CC 2019 or newer. Typical use is colour grading panel for photoshop work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎨 Colour Palettes | Curated colour combinations applied as solid colour layers with blend modes. |
| 🌈 Harmony Sets | Complementary, analogous and split-complementary schemes built from a base tone. |
| 🖌️ Toning Actions | Warm, cool and split-tone looks applied in one click on separate layers. |
| 🎚️ Blend Control | Each layer arrives with a starting opacity and mode that can be changed later. |
| 🧱 Non-destructive Stack | Colour layers stay editable, so a grade can be revised days later. |
| 🗂️ Category Groups | Palettes are grouped by mood and genre instead of one long list. |
